# MDS Ventas Android v2.3.8

El widget **Hacer pedido** ya no utiliza un formulario nativo independiente.
Al tocarlo abre directamente el formulario completo de pedidos dentro de la
aplicación MDS Ventas. De esta forma utiliza la empresa, los clientes, los
permisos y la sesión que ya funcionan en la aplicación.

El reproductor de audios asociados a pedidos también se abre dentro de un
diálogo nativo compacto. Se reproduce al abrirse y se cierra al tocar fuera o
en la X, sin mostrar una pantalla negra.

Para instalar esta versión, genera la APK desde GitHub Actions e instálala
encima de la versión anterior. Antes se debe actualizar el servidor a v70.
